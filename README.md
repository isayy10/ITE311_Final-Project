# SnipBook: A Web-Based Salon & Barbershop Appointment Scheduling System

**Student Name:** Luisa Mae M. Luz
**Course and Section:** BSIT 3-F2
**Project Description:** SnipBook is a responsive web-based business application designed to modernize and streamline the operations of salons and barbershops. It provides clients with a convenient online platform to book appointments, browse services, and choose their preferred stylist or barber, while giving salon owners a centralized system to manage schedules, staff, and customer relationships.
**Technologies Used:** HTML, CSS, JavaScript, PHP, MySQL
